# F1 Winner Predictor (live demo)

Browse 268 Formula 1 races: each driver's grid position, final position and the model's pre-race win probability, a frozen pre-race prediction with its scored result, and a grid what-if tool.

Code, evaluation and the full write-up: https://github.com/divyanshg03/F1-Winner-Prediction

The model gives calibrated winner probabilities after qualifying. It does not pick winners better than "pole wins"; see the repository for the honest numbers.
